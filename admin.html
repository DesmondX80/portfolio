Käyttöönotto

Luo GitHubissa fine-grained personal access token:

  • Repository access: Only select repositories → portfolio
  • Permissions: Contents → Read and write

Token salataan valitsemallasi salasanalla ja tallennetaan repoon tiedostoon admin-token.json. Tiedosto on julkinen, joten käytä pitkää salasanaa.
